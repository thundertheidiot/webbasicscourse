Pure HTML+CSS Image Carousel

The containers are display: inline-block; they each have an id. The image cards are wrapped in a link that points to the corresponding id. Unfortunately the header gets hidden because the page has to scroll down to the card.

The supercontainer has overflow-x: scroll; display: flex; so that the cards extend off screen, and the scroll bars are hidden. Cards get scroll-snap-align: center; so the view snaps to the card.

WebKit is completely untested, should be functional on Firefox and Chromium-based browsers.

I would have wanted the description boxes to be vertically centered relative to the whole page, but I can't quite figure out the CSS for it, the boxes have to be children of the containers to make the :target visibility work.
